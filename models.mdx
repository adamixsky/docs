# Data Models

## Channel
| Field | Description |
|--------|-------------|
| channel_id | Unique identifier |
| username | Channel username |
| name | Display name |
| link | Channel URL |
| subscriber_count | Number of subscribers |
| profile_photo_url | Profile image URL |
| platform | `telegram` or `twitter` |
| calls_analyzed | Number of analyzed calls |
| win_rate | Overall win rate |
| avg_gain | Average gain |
| total_calls_30d | Calls in last 30 days |
| win_rate_30d | 30-day win rate |
| avg_gain_30d | 30-day average gain |
| last_updated | Last update (ISO 8601) |

---

## ChannelCall
| Field | Description |
|--------|-------------|
| id | Call ID |
| channel_id | Channel ID |
| token_address | Token address |
| token_name | Token name |
| token_symbol | Token symbol |
| message_content | Text content |
| called_at | Date of call |
| current_gain | Current gain (%) |
| highest_gain | Highest gain (%) |

---

## TokenResponse
| Field | Description |
|--------|-------------|
| address | Token address |
| name | Token name |
| symbol | Token symbol |
| price | Current price |
| volume | Trading volume |
| total_holders | Number of holders |
| top_10_holders_percentage | % held by top 10 holders |
| avg_gain | Average gain |
| channel_calls | Array of channel calls |
