---
title: "Recent Tokens"
api: "GET /api/tokens/recent"
description: "Get recently called tokens across all channels"
---

## Overview

Retrieve a list of tokens that have been recently called by channels, sorted by the most recent call date.

## Request

<ParamField query="page" default="1" type="integer">
  Page number (starting from 1).
</ParamField>

<ParamField query="limit" default="10" type="integer">
  Number of results per page (max: 100).
</ParamField>

## Response

<ResponseField name="data" type="array">
  An array of [RecentToken](/api-reference/models/token-models#recenttoken) objects.
</ResponseField>

<ResponseField name="page" type="integer">
  The current page number.
</ResponseField>

<ResponseField name="limit" type="integer">
  The number of results per page.
</ResponseField>

<ResponseField name="total" type="integer">
  The total number of results found.
</ResponseField>

<ResponseField name="total_pages" type="integer">
  The total number of pages available.
</ResponseField>

## Example Request

<CodeGroup>

```````bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/tokens/recent?page=1&limit=5"
``````python Python
import requests

response = requests.get(
    "https://prod.api.sauron.outlight.fun/api/tokens/recent",
    params={
        "page": 1,
        "limit": 5
    }
)
data = response.json()
``````javascript JavaScript
const params = new URLSearchParams({
  page: 1,
  limit: 5
});

const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/tokens/recent?${params}`
);
const data = await response.json();
```````

</CodeGroup>
