---
title: 'Recent Tokens'
api: 'GET /api/tokens/recent'
description: 'Get recently called tokens across all channels'
---

## Overview

Retrieve a list of tokens that have been recently called by channels, sorted by the most recent call date.

## Request

<ParamField query="page" type="integer" default="1">
  Page number (starting from 1)
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Number of results per page
</ParamField>

## Response

<ResponseField name="data" type="array">
  Array of recent token objects
  
  <Expandable title="Recent Token Object">
    <ResponseField name="address" type="string">
      Token contract address
    </ResponseField>
    
    <ResponseField name="name" type="string">
      Token name
    </ResponseField>
    
    <ResponseField name="symbol" type="string">
      Token symbol
    </ResponseField>
    
    <ResponseField name="logo_url" type="string">
      URL to token logo
    </ResponseField>
    
    <ResponseField name="chain" type="string">
      Blockchain network (e.g., "solana", "bsc")
    </ResponseField>
    
    <ResponseField name="current_fdv" type="string">
      Current fully diluted valuation
    </ResponseField>
    
    <ResponseField name="ath" type="string">
      All-time high FDV value
    </ResponseField>
    
    <ResponseField name="sufficient_liquidity" type="boolean">
      Whether token has sufficient liquidity
    </ResponseField>
    
    <ResponseField name="unique_channels" type="integer">
      Number of unique channels that called this token
    </ResponseField>
    
    <ResponseField name="total_subscribers" type="integer">
      Combined subscriber count
    </ResponseField>
    
    <ResponseField name="call_count" type="integer">
      Total number of calls
    </ResponseField>
    
    <ResponseField name="most_recent_call" type="string">
      ISO 8601 timestamp of most recent call
    </ResponseField>
    
    <ResponseField name="channel_calls" type="array">
      List of channels that called this token with details
    </ResponseField>
    
    <ResponseField name="website" type="string">
      Token website URL
    </ResponseField>
    
    <ResponseField name="telegram_link" type="string">
      Telegram community link
    </ResponseField>
    
    <ResponseField name="twitter_link" type="string">
      Twitter/X account link
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="page" type="integer">
  Current page number
</ResponseField>

<ResponseField name="limit" type="integer">
  Results per page
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of results
</ResponseField>

<ResponseField name="total_pages" type="integer">
  Total number of pages
</ResponseField>

## Example Request

<CodeGroup>

```bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/tokens/recent?page=1&limit=5"
```

```python Python
import requests

response = requests.get(
    "https://prod.api.sauron.outlight.fun/api/tokens/recent",
    params={
        "page": 1,
        "limit": 5
    }
)

data = response.json()
```

```javascript JavaScript
const params = new URLSearchParams({
  page: 1,
  limit: 5
});

const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/tokens/recent?${params}`
);

const data = await response.json();
```

</CodeGroup>

## Blockchain Networks

| Chain | Description |
|-------|-------------|
| `solana` | Solana blockchain |
| `bsc` | Binance Smart Chain |
| `ethereum` | Ethereum mainnet |
| `polygon` | Polygon network |
| `arbitrum` | Arbitrum One |
| `avalanche` | Avalanche C-Chain |

## Notes

- Tokens are sorted by most recent call date (newest first)
- The `channel_calls` array provides a summary of recent calls from different channels
- `ath` (All-Time High) represents the highest FDV the token has reached
- Results include tokens from multiple blockchain networks
