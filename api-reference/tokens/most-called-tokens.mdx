## Overview

Retrieve tokens ranked by the number of unique channels that mentioned them within a specific timeframe. This endpoint helps identify trending tokens across multiple channels.

## Request

<ParamField query="timeframe" type="string" required>
  Time window for aggregation:
  - `1h` - Last hour
  - `24h` - Last 24 hours
  - `7d` - Last 7 days
  - `30d` - Last 30 days
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number (starting from 1)
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Number of results per page (max: 200)
</ParamField>

## Timeframe Options

| Timeframe | Description | Use Case |
|-----------|-------------|----------|
| `1h` | Last hour | Real-time trending tokens |
| `24h` | Last 24 hours | Daily trending analysis |
| `7d` | Last 7 days | Weekly performance review |
| `30d` | Last 30 days | Monthly trend analysis |

## Ranking Methodology

Tokens are ranked by:
1. **Primary**: Number of unique channels that called the token
2. **Secondary**: Total number of calls
3. **Tertiary**: Combined subscriber count of calling channels

## Notes

- This endpoint is ideal for identifying trending tokens across the ecosystem
- The `unique_channels` metric helps filter out tokens that are only promoted by a single channel
- Results are updated in real-time as new calls are made
- Higher `unique_channels` count typically indicates broader market interest
