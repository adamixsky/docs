## Overview

Retrieve tokens ranked by the number of unique channels that mentioned them within a specific timeframe. This endpoint is ideal for identifying trending tokens across the ecosystem.

## Request

<ParamField query="timeframe" type="string" required>
  Time window for aggregation: `1h`, `24h`, `7d`, or `30d`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number (starting from 1).
</ParamField>

<ParamField query="limit" type="integer" default="15">
  Number of results per page (max: 200).
</ParamField>

## Response

<ResponseField name="data" type="array">
  An array of [MostCalledToken](/api-reference/models/token-models#mostcalledtoken) objects.
</ResponseField>

<ResponseField name="timeframe" type="string">
  The timeframe filter that was applied to the request.
</ResponseField>

<ResponseField name="page" type="integer">
  The current page number.
</ResponseField>

<ResponseField name="limit" type="integer">
  The number of results per page.
</ResponseField>

<ResponseField name="total" type="integer">
  The total number of results found.
</ResponseField>

<ResponseField name="total_pages" type="integer">
  The total number of pages available.
</ResponseField>

## Timeframe Options

| Timeframe | Description | Use Case |
|-----------|-------------|----------|
| `1h` | Last hour | Real-time trending tokens |
| `24h` | Last 24 hours | Daily trending analysis |
| `7d` | Last 7 days | Weekly performance review |
| `30d` | Last 30 days | Monthly trend analysis |

## Ranking Methodology

Tokens are ranked primarily by the number of **unique channels** that have called the token within the timeframe. This metric helps identify broad market interest rather than promotion by a single source.
