## Overview

Retrieve detailed information about a specific token including price data, holder statistics, and all channel calls.

## Request

<ParamField path="address" type="string" required>
  Token contract address
</ParamField>

  Token contract address

## Token Metrics Explained

| Metric          | Description                                                         |
| --------------- | ------------------------------------------------------------------- |
| `price`         | Current price per token in USD. Can be `null`.                      |
| `current_fdv`   | Fully diluted valuation (price × total supply).                     |
| `ath`           | All-time high FDV value.                                            |
| `volume`        | 24-hour trading volume in USD. Can be `null`.                       |
| `total_holders` | Number of unique wallet addresses holding the token. Can be `null`. |
| `avg_gain`      | Average percentage gain across all channel calls.                   |

## Notes

- The `channel_calls` array is sorted by call date (newest first).
- Many fields like `price`, `volume`, and `total_holders` can be `null` if the data is not available.
