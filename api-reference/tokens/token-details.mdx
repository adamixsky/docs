## Overview

Retrieve detailed information about a specific token including price data, holder statistics, and all channel calls.

## Request

<ParamField path="address" type="string" required>

</ParamField>

## Token Metrics Explained

| Metric | Description |
|--------|-------------|
| `price` | Current price per token in USD |
| `current_fdv` | Fully diluted valuation (price × total supply) |
| `volume` | 24-hour trading volume in USD |
| `total_holders` | Number of unique wallet addresses holding the token |
| `top_10_holders_percentage` | Concentration of token supply in top 10 wallets |
| `avg_gain` | Average percentage gain across all channel calls |

## Holder Distribution

The `top_10_holders_percentage` metric helps assess token distribution:
- **< 30%**: Well distributed
- **30-50%**: Moderate concentration
- **> 50%**: High concentration (potential risk)

## Notes

- All price and FDV values are in USD
- Gain percentages are calculated from the FDV at call time
- The `channel_calls` array is sorted by call date (newest first)
- Token must have been called at least once to appear in the system
