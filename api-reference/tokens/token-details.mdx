## Overview

Retrieve detailed information about a specific token, including price data, holder statistics, and a complete history of all channel calls.

## Request

<ParamField path="address" type="string" required>
  The token's contract address.
</ParamField>

## Response

The endpoint returns a single [TokenResponse](/api-reference/models/token-models#tokenresponse) object containing all available details for the specified token.

## Example Request

<CodeGroup>
````bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/tokens/5KfqXLAUq9dVZx6hkKEJteno6GtfoA7idv2iWNtwpump"
````
````python Python
import requests

token_address = "5KfqXLAUq9dVZx6hkKEJteno6GtfoA7idv2iWNtwpump"
response = requests.get(
    f"https://prod.api.sauron.outlight.fun/api/tokens/{token_address}"
)
data = response.json()
````
````javascript JavaScript
const tokenAddress = "5KfqXLAUq9dVZx6hkKEJteno6GtfoA7idv2iWNtwpump";
const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/tokens/${tokenAddress}`

</CodeGroup>

## Token Metrics Explained

The table below explains some of the key metrics available in the response.

| Metric          | Description                                                         |
| --------------- | ------------------------------------------------------------------- |
| `price`         | Current price per token in USD. Can be `null`.                      |
| `current_fdv`   | Fully diluted valuation (price × total supply).                     |
| `ath`           | All-time high FDV value.                                            |
| `volume`        | 24-hour trading volume in USD. Can be `null`.                       |
| `total_holders` | Number of unique wallet addresses holding the token. Can be `null`. |
| `avg_gain`      | Average percentage gain across all channel calls for this token.    |
