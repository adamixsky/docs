## Overview

Search for cryptocurrency tokens by their contract address, name, or symbol. Find tokens that have been called across various channels.

## Request

<ParamField query="q" type="string" required>
  Search query - can be:
  - Token contract address
  - Token name
  - Token symbol
</ParamField>

## Response

<ResponseField name="results" type="array">
  Array of token search result objects
  
  <Expandable title="Token Search Result">
    <ResponseField name="address" type="string">
      Token contract address
    </ResponseField>
    
    <ResponseField name="name" type="string">
      Token name
    </ResponseField>
    
    <ResponseField name="symbol" type="string">
      Token symbol
    </ResponseField>
    
    <ResponseField name="logo_url" type="string">
      URL to token logo
    </ResponseField>
    
    <ResponseField name="current_fdv" type="string">
      Current fully diluted valuation
    </ResponseField>
    
    <ResponseField name="sufficient_liquidity" type="boolean">
      Whether token has sufficient liquidity
    </ResponseField>
    
    <ResponseField name="unique_channels" type="integer">
      Number of unique channels that called this token
    </ResponseField>
    
    <ResponseField name="total_subscribers" type="integer">
      Combined subscriber count of all channels
    </ResponseField>
    
    <ResponseField name="call_count" type="integer">
      Total number of calls
    </ResponseField>
    
    <ResponseField name="last_updated" type="string">
      ISO 8601 timestamp of last update
    </ResponseField>
    
    <ResponseField name="website" type="string">
      Token website URL
    </ResponseField>
    
    <ResponseField name="telegram_link" type="string">
      Telegram community link
    </ResponseField>
    
    <ResponseField name="twitter_link" type="string">
      Twitter/X account link
    </ResponseField>
  </Expandable>
</ResponseField>

## Search Tips

- **By Address**: Use the full contract address for exact match
- **By Symbol**: Search is case-insensitive (e.g., "BTC", "btc", "Btc" all work)
- **By Name**: Partial matches are supported (e.g., "moon" will find "Moon Token", "MoonShot", etc.)

## Response Fields

| Field | Description |
|-------|-------------|
| `current_fdv` | Current fully diluted valuation in USD |
| `sufficient_liquidity` | Indicates if token has enough liquidity for trading |
| `unique_channels` | Number of different channels that have called this token |
| `total_subscribers` | Combined subscriber count across all channels |
| `call_count` | Total number of times token has been called |

## Notes

- Results are sorted by relevance to the search query
- The search is performed across multiple blockchains
- Only tokens with at least one channel call are returned
