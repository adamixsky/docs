## Overview

Search for cryptocurrency tokens by their contract address, name, or symbol. The search is performed across multiple blockchains and results are sorted by relevance.

## Request

<ParamField query="q" type="string" required>
  Search query. Can be a token contract address, name, or symbol.
</ParamField>

## Response

The endpoint returns a **direct JSON array** of [TokenSearchResult](/api-reference/models/token-models#tokensearchresult) objects. Note that unlike other list endpoints, there is no wrapper object.

## Example Request

<CodeGroup>

```````bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/tokens/search?q=SOL"
``````python Python
```````

## Search Tips

- **By Address**: Use the full contract address for an exact match.
- **By Symbol**: The search is case-insensitive (e.g., "sol" and "SOL" yield the same results).
- **By Name**: Partial matches are supported (e.g., "wrapped" will find "Wrapped SOL").
