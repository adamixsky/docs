## Overview

Retrieve comprehensive information about a specific channel, including detailed statistics for multiple timeframes. The response provides a flat structure with performance metrics suffixed by their respective time periods (e.g., `_1d`, `_7d`, `_all`).

## Request

<ParamField path="channelId" type="string" required>
  Unique channel identifier (e.g., "@ExampleChannel")
</ParamField>

## Response

The endpoint returns a single [ChannelInfo](/api-reference/models/channel-models#channelinfo) object containing all available details for the channel.

## Example Request

<CodeGroup>
```bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels/@MontyAlerts/info"
``````python Python
import requests

channel_id = "@MontyAlerts"
response = requests.get(
    f"https://prod.api.sauron.outlight.fun/api/channels/{channel_id}/info"
)

``````javascript JavaScript
const channelId = "@MontyAlerts";
const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/channels/${channelId}/info`

const data = await response.json();
```
</CodeGroup>

## Metrics Explained

The following table explains some of the key performance metrics returned in the `ChannelInfo` object.

| Metric                  | Description                          |
| ----------------------- | ------------------------------------ |
| `win_rate`              | Percentage of profitable calls       |
| `avg_gain`              | Average percentage gain across calls |
| `x5_rate_all`           | Percentage achieving 5x returns      |
| `x10_rate_all`          | Percentage achieving 10x returns     |
| `intelligent_sl`        | Suggested stop-loss percentage       |
| `intelligent_tp`        | Suggested take-profit percentage     |
| `profit_risk_ratio`     | Ratio of potential profit to risk    |
| `rds_score`             | Overall channel performance score    |
| `survival_rate_percent` | Token survival rate                  |
| `time_to_ath_minutes`   | Average time to peak value           |
