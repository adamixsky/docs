title: 'Channel Details'
description: 'Get detailed information and statistics for a specific channel'
---

## Overview

Retrieve comprehensive information about a specific channel including detailed statistics for multiple timeframes. The response provides a flat structure with performance metrics suffixed by their respective time periods (e.g., _1d, _7d, _all).

## Request

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| channelId | string | yes | Unique channel identifier (e.g., "@ExampleChannel") |

## Response

| Field | Type | Description |
|-------|------|-------------|
| channel_id | string | Unique identifier for the channel |
| username | string | Channel username |
| name | string | Display name of the channel |
| link | string | URL to the channel |
| profile_photo_url | string | URL to the channel's profile picture |
| platform | string | Platform: "telegram" or "twitter" |
| subscriber_count | integer | Number of subscribers |
| calls_analyzed | integer | Number of calls that have been fully analyzed |
| total_calls_1d | integer | Total calls in the last 24 hours |
| total_calls_3d | integer | Total calls in the last 3 days |
| total_calls_7d | integer | Total calls in the last 7 days |
| total_calls_14d | integer | Total calls in the last 14 days |
| total_calls_30d | integer | Total calls in the last 30 days |
| total_calls_all | integer | Total calls of all time |
| win_rate_1d | number | Win rate for the last 24 hours |
| win_rate_3d | number | Win rate for the last 3 days |
| win_rate_7d | number | Win rate for the last 7 days |
| win_rate_14d | number | Win rate for the last 14 days |
| win_rate_30d | number | Win rate for the last 30 days |
| win_rate_all | number | Win rate for all time |
| avg_gain_1d | number | Average gain for the last 24 hours |
| avg_gain_3d | number | Average gain for the last 3 days |
| avg_gain_7d | number | Average gain for the last 7 days |
| avg_gain_14d | number | Average gain for the last 14 days |
| avg_gain_30d | number | Average gain for the last 30 days |
| avg_gain_all | number | Average gain for all time |
| x5_rate_all | number | Percentage of calls achieving 5x returns (all time) |
| x10_rate_all | number | Percentage of calls achieving 10x returns (all time) |
| unique_tokens | integer | Number of unique tokens called |
| last_call_at | string | ISO 8601 timestamp of the most recent call |
| first_call_at | string | ISO 8601 timestamp of the first call |
| intelligent_sl | number or null | Intelligent stop-loss value |
| intelligent_tp | number or null | Intelligent take-profit value |
| profit_risk_ratio | number or null | Profit to risk ratio |
| rds_score | number or null | RDS (Risk-Diversification-Success) score |
| survival_rate_percent | number or null | Percentage of tokens that maintained value |
| time_to_ath_minutes | number or null | Average time to reach all-time high in minutes |
| status | string | Analysis status of the channel (e.g., "pending") |
| updated_at | string or null | ISO 8601 timestamp of the last data update |

## Example Request

```bash
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels/@AltcoinGordon/info"
```

```python
import requests

channel_id = "@AltcoinGordon"
response = requests.get(
    f"https://prod.api.sauron.outlight.fun/api/channels/{channel_id}/info"
)

data = response.json()
```

```javascript
const channelId = "@AltcoinGordon";
const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/channels/${channelId}/info`
);

const data = await response.json();
```

## Metrics Explained

| Metric | Description |
|--------|-------------|
| win_rate | Percentage of profitable calls |
| avg_gain | Average percentage gain across calls |
| x5_rate | Percentage achieving 5x returns |
| x10_rate | Percentage achieving 10x returns |
| intelligent_sl | Suggested stop-loss percentage |
| intelligent_tp | Suggested take-profit percentage |
| profit_risk_ratio | Ratio of potential profit to risk |
| rds_score | Overall channel performance score |
| survival_rate_percent | Token survival rate |
| time_to_ath_minutes | Average time to peak value |
