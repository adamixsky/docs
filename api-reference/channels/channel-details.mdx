---
title: 'Channel Details'
api: 'GET /api/channels/{channelId}/info'
description: 'Get detailed information and statistics for a specific channel'
---

## Overview

Retrieve comprehensive information about a specific channel including detailed statistics for multiple timeframes.

## Request

<ParamField path="channelId" type="string" required>
  Unique channel identifier (e.g., "@ExampleChannel")
</ParamField>

## Response

<ResponseField name="channel_id" type="string">
  Unique identifier for the channel
</ResponseField>

<ResponseField name="username" type="string">
  Channel username
</ResponseField>

<ResponseField name="name" type="string">
  Display name of the channel
</ResponseField>

<ResponseField name="link" type="string">
  URL to the channel
</ResponseField>

<ResponseField name="subscriber_count" type="integer">
  Number of subscribers
</ResponseField>

<ResponseField name="platform" type="string">
  Platform: "telegram" or "twitter"
</ResponseField>

<ResponseField name="statistics" type="object">
  Performance statistics for different time periods
  
  <Expandable title="Statistics Object">
    <ResponseField name="1d" type="object">
      Statistics for last 24 hours
    </ResponseField>
    
    <ResponseField name="3d" type="object">
      Statistics for last 3 days
    </ResponseField>
    
    <ResponseField name="7d" type="object">
      Statistics for last 7 days
    </ResponseField>
    
    <ResponseField name="14d" type="object">
      Statistics for last 14 days
    </ResponseField>
    
    <ResponseField name="30d" type="object">
      Statistics for last 30 days
    </ResponseField>
    
    <ResponseField name="all" type="object">
      All-time statistics
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="first_call_at" type="string">
  ISO 8601 timestamp of first call
</ResponseField>

<ResponseField name="last_call_at" type="string">
  ISO 8601 timestamp of last call
</ResponseField>

<ResponseField name="unique_tokens" type="integer">
  Number of unique tokens called
</ResponseField>

<ResponseField name="intelligent_sl" type="number">
  Intelligent stop-loss value
</ResponseField>

<ResponseField name="intelligent_tp" type="number">
  Intelligent take-profit value
</ResponseField>

<ResponseField name="profit_risk_ratio" type="number">
  Profit to risk ratio
</ResponseField>

<ResponseField name="rds_score" type="number">
  RDS (Risk-Diversification-Success) score
</ResponseField>

<ResponseField name="survival_rate_percent" type="number">
  Percentage of tokens that maintained value
</ResponseField>

<ResponseField name="time_to_ath_minutes" type="number">
  Average time to reach all-time high in minutes
</ResponseField>

## Example Request

<CodeGroup>

```bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels/@TopCrypto/info"
```

```python Python
import requests

channel_id = "@TopCrypto"
response = requests.get(
    f"https://prod.api.sauron.outlight.fun/api/channels/{channel_id}/info"
)

data = response.json()
```

```javascript JavaScript
const channelId = "@TopCrypto";
const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/channels/${channelId}/info`
);

const data = await response.json();
```

</CodeGroup>

## Statistics Periods

| Period | Description |
|--------|-------------|
| `1d` | Last 24 hours |
| `3d` | Last 3 days |
| `7d` | Last 7 days |
| `14d` | Last 14 days |
| `30d` | Last 30 days |
| `all` | All-time data |

## Metrics Explained

| Metric | Description |
|--------|-------------|
| `win_rate` | Percentage of profitable calls |
| `avg_gain` | Average percentage gain across calls |
| `x5_rate` | Percentage achieving 5x returns |
| `x10_rate` | Percentage achieving 10x returns |
| `intelligent_sl` | Suggested stop-loss percentage |
| `intelligent_tp` | Suggested take-profit percentage |
| `profit_risk_ratio` | Ratio of potential profit to risk |
| `rds_score` | Overall channel performance score |
| `survival_rate_percent` | Token survival rate |
| `time_to_ath_minutes` | Average time to peak value |
