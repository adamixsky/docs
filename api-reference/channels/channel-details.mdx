## Overview

Retrieve comprehensive information about a specific channel. The response includes both a flat structure with basic performance metrics (e.g., `win_rate`) and a nested `analytics_by_timeframe` object with more advanced, calculated statistics.

## Request

<ParamField path="channelId" type="string" required>
  Unique channel identifier (e.g., "@adamowicztw")
</ParamField>

## Response

The endpoint returns a single [ChannelInfo](/api-reference/models/channel-models#channelinfo) object containing all available details for the channel.

## Metrics Explained

The following table explains some of the key performance metrics returned in the `ChannelInfo` object.

| Metric                  | Description                                                               |
| ----------------------- | ------------------------------------------------------------------------- |
| `win_rate`              | Percentage of profitable calls.                                           |
| `avg_gain`              | Average percentage gain across all calls in the chosen timeframe.         |
| `x5_rate`               | Percentage of calls achieving at least 5x returns.                        |
| `x10_rate`              | Percentage of calls achieving at least 10x returns.                       |
| `rds_score`             | Risk-Diversification-Success score (0-100). A higher score is better.     |
| `channel_style`         | An algorithmic classification of the channel's calling behavior.          |
| `survival_rate_percent` | Percentage of called tokens that maintained their value over a period.    |
| `intelligent_sl` / `tp` | Suggested stop-loss and take-profit percentages based on historical data. |

_All of the metrics are calculated from calls that occured within the chosen timeframe. For example '7d' timeframe includes calls from the last 7 days._
