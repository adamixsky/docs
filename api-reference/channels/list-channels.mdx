## Overview

Retrieve a paginated list of channels with advanced sorting options by various performance metrics.

## Request

<ParamField query="page" type="integer" default="1">
  Page number (starting from 1)
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of results per page (1-200)
</ParamField>

<ParamField query="timeframe" type="string">
  Time window for metrics. Options: `1h`, `24h`, `7d`, `30d`
  
  Example: `30d` for 30-day metrics
</ParamField>

<ParamField query="sort" type="string">
  Sort field. Options:
  - `win_rate` - Sort by win rate
  - `avg_gain` - Sort by average gain
  - `subscriber_count` - Sort by subscriber count
  - `total_calls` - Sort by number of calls
</ParamField>

<ParamField query="order" type="string" default="desc">
  Sort direction: `asc` or `desc`
</ParamField>

## Response

<ResponseField name="channels" type="array">
  Array of channel objects
</ResponseField>

<ResponseField name="totalChannels" type="integer">
  Total number of channels available
</ResponseField>

<ResponseField name="totalPages" type="integer">
  Total number of pages
</ResponseField>

<ResponseField name="currentPage" type="integer">
  Current page number
</ResponseField>

## Example Request

<CodeGroup>

```bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels?page=1&limit=10&timeframe=30d&sort=win_rate&order=desc"
```

```python Python
import requests

response = requests.get(
    "https://prod.api.sauron.outlight.fun/api/channels",
    params={
        "page": 1,
        "limit": 10,
        "timeframe": "30d",
        "sort": "win_rate",
        "order": "desc"
    }
)

data = response.json()
```

```javascript JavaScript
const params = new URLSearchParams({
  page: 1,
  limit: 10,
  timeframe: '30d',
  sort: 'win_rate',
  order: 'desc'
});

const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/channels?${params}`
);

const data = await response.json();
```

</CodeGroup>

## Sorting Options

| Sort Field | Description |
|------------|-------------|
| `win_rate` | Percentage of successful calls |
| `avg_gain` | Average percentage gain across all calls |
| `subscriber_count` | Number of channel subscribers |
| `total_calls` | Total number of calls analyzed |
| `x5_rate` | Percentage of calls that achieved 5x returns |
| `x10_rate` | Percentage of calls that achieved 10x returns |

## Timeframe Options

| Timeframe | Description |
|-----------|-------------|
| `1h` | Last hour metrics |
| `24h` | Last 24 hours metrics |
| `7d` | Last 7 days metrics |
| `30d` | Last 30 days metrics |
| `all` | All-time metrics |
