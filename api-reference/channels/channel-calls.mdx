---

## Overview

Retrieve a list of all tokens that have been called by a specific channel, with detailed performance metrics for each call.

## Request

<ParamField path="channelId" type="string" required>
  Channel username (with or without "@" prefix, e.g., "@MontyAlerts")
</ParamField>

<ParamField query="page" default="1" type="integer">
  Page number (starting from 1)
</ParamField>

<ParamField query="limit" default="20" type="integer">
  Number of results per page (1-500)
</ParamField>

<ParamField query="sort" type="string">
  Sort field options:

  - `called_at` - Date of call
  - `highest_gain` - Maximum gain achieved
  - `current_gain` - Current gain
  - `highest_fdv` - Highest FDV reached
  - `fdv_at_call` - FDV at time of call
</ParamField>

<ParamField query="order" default="desc" type="string">
  Sort direction: `asc` or `desc`
</ParamField>

## Response

<ResponseField name="calls" type="array">
  An array of [ChannelCall](/api-reference/models/channel-models#channelcall) objects.
</ResponseField>

<ResponseField name="totalCalls" type="integer">
  Total number of calls found for this channel.
</ResponseField>

<ResponseField name="totalPages" type="integer">
  Total number of pages available.
</ResponseField>

<ResponseField name="currentPage" type="integer">
  The current page number.
</ResponseField>

## Example Request

<CodeGroup>

```bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels/@MontyAlerts/calls?page=1&limit=10&sort=highest_gain&order=desc"
```


```python Python
import requests

channel_username = "@MontyAlerts"
response = requests.get(
    f"https://prod.api.sauron.outlight.fun/api/channels/{channel_username}/calls",
    params={
        "page": 1,
        "limit": 10,
        "sort": "highest_gain",
        "order": "desc"
    }
)

data = response.json()
```


```javascript JavaScript
const channelUsername = "@MontyAlerts";
const params = new URLSearchParams({
  page: 1,
  limit: 10,
  sort: 'highest_gain',
  order: 'desc'
});

const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/channels/${channelUsername}/calls?${params}`
);

const data = await response.json();
```

</CodeGroup>
