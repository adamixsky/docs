## Overview

Retrieve a list of all tokens that have been called by a specific channel, with detailed performance metrics for each call.

## Request

<ParamField path="channelId" type="string" required>
  Channel username (with or without "@" prefix)
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number (starting from 1)
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of results per page (1-500)
</ParamField>

<ParamField query="sort" type="string">
  Sort field options:
  - `called_at` - Date of call
  - `highest_gain` - Maximum gain achieved
  - `current_gain` - Current gain
  - `highest_fdv` - Highest FDV reached
  - `fdv_at_call` - FDV at time of call
</ParamField>

<ParamField query="order" type="string" default="desc">
  Sort direction: `asc` or `desc`
</ParamField>

## Example Request

<CodeGroup>

```bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels/TopCrypto/calls?page=1&limit=10&sort=highest_gain&order=desc"
```

```python Python
import requests

channel_username = "TopCrypto"
response = requests.get(
    f"https://prod.api.sauron.outlight.fun/api/channels/{channel_username}/calls",
    params={
        "page": 1,
        "limit": 10,
        "sort": "highest_gain",
        "order": "desc"
    }
)

data = response.json()
```

```javascript JavaScript
const channelUsername = "TopCrypto";
const params = new URLSearchParams({
  page: 1,
  limit: 10,
  sort: 'highest_gain',
  order: 'desc'
});

const response = await fetch(
  `https://prod.api.sauron.outlight.fun/api/channels/${channelUsername}/calls?${params}`
);

const data = await response.json();
```

</CodeGroup>

## Sort Options

| Sort Field | Description |
|------------|-------------|
| `called_at` | Date and time of the call |
| `highest_gain` | Maximum gain percentage achieved |
| `current_gain` | Current gain percentage |
| `highest_fdv` | Highest FDV reached |
| `fdv_at_call` | FDV at the time of call |

## Notes

- The `channelId` parameter accepts usernames with or without the "@" prefix
- FDV values are returned as strings for precision
- Gain values are in percentage (e.g., 100 = 100% gain)
- Results can be filtered and sorted to find top performing calls
