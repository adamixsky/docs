## Overview

This page documents the data models used for token-related endpoints in the Outlight API.

## TokenSearchResult

Basic token information returned from search endpoints.

```typescript
interface TokenSearchResult {
  address: string;
  name: string;
  symbol: string;
  logo_url: string;
  current_fdv: string;
  sufficient_liquidity: boolean;
  unique_channels: number;
  total_subscribers: number;
  call_count: number;
  last_updated: string;
  website?: string;
  telegram_link?: string;
  twitter_link?: string;
}
```

### Field Details

| Field | Type | Description |
|-------|------|-------------|
| `address` | string | Token contract address |
| `name` | string | Official token name |
| `symbol` | string | Token ticker symbol |
| `logo_url` | string | URL to token logo image |
| `current_fdv` | string | Current fully diluted valuation in USD |
| `sufficient_liquidity` | boolean | Whether token has enough liquidity for trading |
| `unique_channels` | integer | Number of different channels that called this token |
| `total_subscribers` | integer | Combined subscriber count of all calling channels |
| `call_count` | integer | Total number of times token was called |
| `last_updated` | string | ISO 8601 timestamp of last data update |
| `website` | string | Official token website (optional) |
| `telegram_link` | string | Telegram community link (optional) |
| `twitter_link` | string | Twitter/X account link (optional) |

## RecentToken

Token information with recent call data and blockchain details.

```typescript
interface RecentToken extends TokenSearchResult {
  chain: "solana" | "bsc" | "ethereum" | "polygon" | "arbitrum" | "avalanche";
  ath: string;
  most_recent_call: string;
  channel_calls: ChannelCallSummary[];
}

interface ChannelCallSummary {
  channel_id: string;
  channel_name: string;
  called_at: string;
  gain: number;
}
```

### Additional Fields

| Field | Type | Description |
|-------|------|-------------|
| `chain` | enum | Blockchain network where token is deployed |
| `ath` | string | All-time high FDV value |
| `most_recent_call` | string | Timestamp of the most recent channel call |
| `channel_calls` | array | Summary of recent calls from different channels |

## MostCalledToken

Token ranked by call frequency within a timeframe.

```typescript
interface MostCalledToken extends RecentToken {
  total_calls: number;
  last_call_at: string;
  channel_calls: DetailedChannelCall[];
}

interface DetailedChannelCall {
  channel_id: string;
  channel_name: string;
  subscriber_count: number;
  call_count: number;
  first_call: string;
  last_call: string;
}
```

### Additional Fields

| Field | Type | Description |
|-------|------|-------------|
| `total_calls` | integer | Total calls within the specified timeframe |
| `last_call_at` | string | Timestamp of the last call |
| `channel_calls` | array | Detailed breakdown of calls per channel |

## TokenResponse

Complete token information with all details.

```typescript
interface TokenResponse {
  address: string;
  name: string;
  symbol: string;
  logo_url: string;
  chain: string;
  price: string;
  current_fdv: string;
  volume: string;
  total_holders: number;
  top_10_holders_percentage: number;
  sufficient_liquidity: boolean;
  unique_channels: number;
  total_subscribers: number;
  call_count: number;
  avg_gain: string;
  website?: string;
  telegram_link?: string;
  twitter_link?: string;
  channel_calls: TokenChannelCall[];
}

interface TokenChannelCall {
  channel_id: string;
  channel_name: string;
  channel_link: string;
  subscriber_count: number;
  message_link: string;
  called_at: string;
  fdv_at_call: string;
  current_gain: number;
  highest_gain: number;
}
```

### Complete Token Fields

| Field | Type | Description |
|-------|------|-------------|
| `price` | string | Current price per token in USD |
| `volume` | string | 24-hour trading volume in USD |
| `total_holders` | integer | Number of unique wallet addresses holding the token |
| `top_10_holders_percentage` | number | Percentage of supply held by top 10 wallets |
| `avg_gain` | string | Average gain percentage across all calls |
| `channel_calls` | array | Complete list of all channel calls with details |

## Metrics Explained

### Fully Diluted Valuation (FDV)
```
FDV = Current Price × Total Supply
```

### Gain Calculation
```
Gain % = ((Current FDV - FDV at Call) / FDV at Call) × 100
```

### Liquidity Assessment
A token has `sufficient_liquidity = true` when:
- Liquidity pool value > $50,000
- Daily volume > $10,000
- Spread < 2%

## Example Usage

### TypeScript
```typescript
// Fetching token details
async function getTokenDetails(address: string): Promise<TokenResponse> {
  const response = await fetch(
    `https://prod.api.sauron.outlight.fun/api/tokens/${address}`
  );
  
  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }
  
  return await response.json() as TokenResponse;
}

// Analyzing token performance
const token = await getTokenDetails("0x123...");
const avgGain = parseFloat(token.avg_gain);
const isHighPerformer = avgGain > 500;

console.log(`Token: ${token.name} (${token.symbol})`);
console.log(`Average Gain: ${avgGain}%`);
console.log(`High Performer: ${isHighPerformer ? 'Yes' : 'No'}`);
console.log(`Called by ${token.unique_channels} channels`);
```

### Python
```python
from typing import Dict, Any
import requests

def get_token_details(address: str) -> Dict[str, Any]:
    """Fetch complete token information"""
    response = requests.get(
        f"https://prod.api.sauron.outlight.fun/api/tokens/{address}"
    )
    response.raise_for_status()
    return response.json()

def analyze_token_performance(token: Dict[str, Any]) -> Dict[str, Any]:
    """Analyze token performance metrics"""
    avg_gain = float(token['avg_gain'])
    
    return {
        'name': token['name'],
        'symbol': token['symbol'],
        'avg_gain': avg_gain,
        'high_performer': avg_gain > 500,
        'risk_level': 'High' if token['top_10_holders_percentage'] > 50 else 'Medium',
        'popularity': token['unique_channels']
    }

# Example usage
token = get_token_details("0x123...")
analysis = analyze_token_performance(token)

print(f"Token: {analysis['name']} ({analysis['symbol']})")
print(f"Average Gain: {analysis['avg_gain']}%")
print(f"Risk Level: {analysis['risk_level']}")
```

## Data Precision

### String vs Number Fields

Many numeric values are returned as strings to maintain precision:

```typescript
// FDV values as strings for large numbers
current_fdv: "12500000.50"  // Preserves decimal precision

// Gain values as numbers for calculations
current_gain: 245.67  // Direct percentage value
```

### Best Practices

1. **Parse strings carefully**: Use appropriate parsing methods for numeric strings
2. **Handle optional fields**: Check for existence before accessing optional fields
3. **Validate data types**: Ensure proper type handling in strongly-typed languages
4. **Cache token data**: Token details change frequently, cache with appropriate TTL
