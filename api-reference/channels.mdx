## Overview

This page documents the data models used for channel-related endpoints in the Outlight API.

## Channel

Basic channel information object used across multiple endpoints.

```typescript
interface Channel {
  channel_id: string;           // Unique identifier (e.g., "@ExampleChannel")
  username: string;              // Channel username
  name: string;                  // Display name
  link: string;                  // Channel URL
  subscriber_count: number;      // Number of subscribers
  profile_photo_url: string;     // Profile picture URL
  platform: "telegram" | "twitter"; // Platform
  calls_analyzed: number;        // Number of analyzed calls
  win_rate: string;              // Win rate percentage
  avg_gain: string;              // Average gain percentage
  total_calls_30d: number;       // Calls in last 30 days
  win_rate_30d: string;          // 30-day win rate
  avg_gain_30d: string;          // 30-day average gain
  x5_rate: string;               // Rate of 5x returns
  x10_rate: string;              // Rate of 10x returns
  last_updated: string;          // ISO 8601 timestamp
}
```

### Field Details

| Field | Type | Description |
|-------|------|-------------|
| `channel_id` | string | Unique identifier, typically starts with "@" |
| `username` | string | Channel username without "@" |
| `name` | string | Display name shown in the channel |
| `link` | string | Direct URL to the channel |
| `subscriber_count` | integer | Current subscriber/follower count |
| `profile_photo_url` | string | URL to channel's profile picture |
| `platform` | enum | Either "telegram" or "twitter" |
| `calls_analyzed` | integer | Total number of token calls analyzed |
| `win_rate` | string | Percentage of profitable calls (0-100) |
| `avg_gain` | string | Average percentage gain across all calls |
| `total_calls_30d` | integer | Number of calls in the last 30 days |
| `win_rate_30d` | string | Win rate for the last 30 days |
| `avg_gain_30d` | string | Average gain for the last 30 days |
| `x5_rate` | string | Percentage of calls achieving 5x returns |
| `x10_rate` | string | Percentage of calls achieving 10x returns |
| `last_updated` | string | Last data update timestamp |

## ChannelInfo

Extended channel information with detailed statistics for multiple timeframes.

```typescript
interface ChannelInfo extends Channel {
  statistics: {
    "1d"?: TimeframeStats;
    "3d"?: TimeframeStats;
    "7d"?: TimeframeStats;
    "14d"?: TimeframeStats;
    "30d"?: TimeframeStats;
    "all"?: TimeframeStats;
  };
  first_call_at: string;
  last_call_at: string;
  unique_tokens: number;
  intelligent_sl: number;
  intelligent_tp: number;
  profit_risk_ratio: number;
  rds_score: number;
  survival_rate_percent: number;
  time_to_ath_minutes: number;
}

interface TimeframeStats {
  calls_count: number;
  win_rate: string;
  avg_gain: string;
  x5_rate: string;
  x10_rate: string;
}
```

### Additional Fields

| Field | Type | Description |
|-------|------|-------------|
| `statistics` | object | Performance metrics for different time periods |
| `first_call_at` | string | Timestamp of the channel's first call |
| `last_call_at` | string | Timestamp of the most recent call |
| `unique_tokens` | integer | Number of different tokens called |
| `intelligent_sl` | number | Suggested stop-loss percentage |
| `intelligent_tp` | number | Suggested take-profit percentage |
| `profit_risk_ratio` | number | Ratio of potential profit to risk |
| `rds_score` | number | Risk-Diversification-Success score (0-100) |
| `survival_rate_percent` | number | Percentage of tokens that maintained value |
| `time_to_ath_minutes` | number | Average time to reach all-time high |

## ChannelCall

Represents a specific token call made by a channel.

```typescript
interface ChannelCall {
  id: string;
  channel_id: string;
  token_address: string;
  token_name: string;
  token_symbol: string;
  token_logo_url: string;
  message_id: string;
  message_link: string;
  message_content: string;
  message_html: string;
  called_at: string;
  fdv_at_call: string;
  current_fdv: string;
  highest_fdv: string;
  lowest_fdv: string;
  highest_fdv_at: string;
  lowest_fdv_at: string;
  current_gain: number;
  highest_gain: number;
}
```

### Field Details

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique call identifier |
| `channel_id` | string | Channel that made the call |
| `token_address` | string | Token contract address |
| `token_name` | string | Name of the called token |
| `token_symbol` | string | Token ticker symbol |
| `token_logo_url` | string | URL to token logo |
| `message_id` | string | Original message ID |
| `message_link` | string | Direct link to the call message |
| `message_content` | string | Plain text message content |
| `message_html` | string | HTML formatted message |
| `called_at` | string | Timestamp when call was made |
| `fdv_at_call` | string | FDV at the time of call |
| `current_fdv` | string | Current FDV |
| `highest_fdv` | string | Highest FDV reached |
| `lowest_fdv` | string | Lowest FDV reached |
| `highest_fdv_at` | string | Timestamp of highest FDV |
| `lowest_fdv_at` | string | Timestamp of lowest FDV |
| `current_gain` | number | Current gain percentage |
| `highest_gain` | number | Highest gain percentage achieved |

## Performance Metrics

### Win Rate Calculation
```
Win Rate = (Profitable Calls / Total Calls) × 100
```

### Average Gain Calculation
```
Average Gain = Sum of All Gains / Number of Calls
```

### X-Rate Calculation
```
X5 Rate = (Calls with ≥500% gain / Total Calls) × 100
X10 Rate = (Calls with ≥1000% gain / Total Calls) × 100
```

## Example Usage

### TypeScript
```typescript
// Fetching channel details
async function getChannelInfo(channelId: string): Promise<ChannelInfo> {
  const response = await fetch(
    `https://prod.api.sauron.outlight.fun/api/channels/${channelId}/info`
  );
  
  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }
  
  return await response.json() as ChannelInfo;
}

// Using the data
const channel = await getChannelInfo("@TopCrypto");
console.log(`Channel: ${channel.name}`);
console.log(`Win Rate: ${channel.win_rate}%`);
console.log(`RDS Score: ${channel.rds_score}`);
```

### Python
```python
from typing import Dict, Any
import requests

def get_channel_info(channel_id: str) -> Dict[str, Any]:
    """Fetch detailed channel information"""
    response = requests.get(
        f"https://prod.api.sauron.outlight.fun/api/channels/{channel_id}/info"
    )
    response.raise_for_status()
    return response.json()

# Using the data
channel = get_channel_info("@TopCrypto")
print(f"Channel: {channel['name']}")
print(f"Win Rate: {channel['win_rate']}%")
print(f"RDS Score: {channel['rds_score']}")
```
