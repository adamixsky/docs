## Overview

The Outlight API provides programmatic access to cryptocurrency token call data across social media channels. You can use it to track performance metrics, analyze channel statistics, and monitor token movements in real-time.

This document provides a high-level overview of the API's structure, resources, and core concepts.

## Base Configuration

All API requests should be made to the following base URL.

<ParamField body="base_url" type="string" required>
  API Base URL: `https://prod.api.sauron.outlight.fun`
</ParamField>

<ParamField body="version" type="string" required>
  API Version: `1.0.0`
</ParamField>

## Available Resources

The API is organized into two main resources: Channels and Tokens.

### 🔍 Channels API

Track and analyze social media channels that make cryptocurrency calls.
- [**Search channels**](/api-reference/channels/search-channels) - Find channels by keywords.
- [**List channels**](/api-reference/channels/list-channels) - Get paginated channel lists with metrics.
- [**Channel details**](/api-reference/channels/channel-details) - Retrieve comprehensive channel statistics.
- [**Channel calls**](/api-reference/channels/channel-calls) - View tokens called by specific channels.

### 🪙 Tokens API

Monitor and analyze token performance based on channel calls.
- [**Search tokens**](/api-reference/tokens/search-tokens) - Find tokens by address, name, or symbol.
- [**Recent tokens**](/api-reference/tokens/recent-tokens) - Get recently called tokens.
- [**Most called tokens**](/api-reference/tokens/most-called-tokens) - Discover trending tokens.
- [**Token details**](/api-reference/tokens/token-details) - Access complete token information.

## Core Concepts

### Response & Error Formats
All API endpoints return JSON. We use standardized structures for paginated lists, search results, and errors.
<br/>
<a href="/api-reference/models/response-models">
  → See detailed Response & Error Models
</a>

### Data Types
- **Dates and Times**: All timestamps use ISO 8601 format (e.g., `2025-10-08T12:00:00Z`).
- **Numeric Values**: Many numeric fields (like `fdv_at_call`) are returned as strings to maintain precision.

### Rate Limits
To ensure fair usage, all public endpoints are rate-limited.
