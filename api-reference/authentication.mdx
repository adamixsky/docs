## Overview

The Outlight API currently provides public access to most endpoints. No authentication is required for the endpoints documented in this API reference.

## Public Access

All endpoints documented in this reference are publicly accessible:

- ✅ **Channels API** - Search, list, and analyze channels
- ✅ **Tokens API** - Search, track, and analyze tokens
- ✅ **Data Models** - All response data models

## Request Headers

While authentication is not required, we recommend including standard headers in your requests:

```http
GET /api/channels/search?q=crypto&limit=10
Host: prod.api.sauron.outlight.fun
Content-Type: application/json
Accept: application/json
User-Agent: YourAppName/1.0
```

## Rate Limiting

<Warning>
  Public endpoints may be subject to rate limiting to ensure fair usage and system stability.
</Warning>

### Rate Limit Headers

Monitor these response headers for rate limit information:

| Header | Description |
|--------|-------------|
| `X-RateLimit-Limit` | Maximum requests per time window |
| `X-RateLimit-Remaining` | Remaining requests in current window |
| `X-RateLimit-Reset` | Unix timestamp when limit resets |

### Rate Limit Response

When rate limited, you'll receive a 429 response:

```json
{
  "error": {
    "code": "RATE_LIMITED",
    "message": "Too many requests. Please try again later.",
    "retry_after": 60
  }
}
```

## Best Practices

### 1. Implement Retry Logic

Handle rate limits gracefully:

```python
import time
import requests

def api_request_with_retry(url, params, max_retries=3):
    for attempt in range(max_retries):
        response = requests.get(url, params=params)
        
        if response.status_code == 429:
            retry_after = response.json().get('error', {}).get('retry_after', 60)
            time.sleep(retry_after)
            continue
            
        return response
    
    raise Exception("Max retries exceeded")
```

### 2. Cache Responses

Cache frequently accessed data to reduce API calls:

```javascript
const cache = new Map();
const CACHE_TTL = 5 * 60 * 1000; // 5 minutes

async function getCachedData(key, fetchFn) {
  const cached = cache.get(key);
  
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    return cached.data;
  }
  
  const data = await fetchFn();
  cache.set(key, { data, timestamp: Date.now() });
  
  return data;
}
```

### 3. Use Pagination Efficiently

Request only the data you need:

```python
# Good: Request specific page size
response = requests.get(
    "https://prod.api.sauron.outlight.fun/api/channels",
    params={"page": 1, "limit": 20}
)

# Avoid: Requesting maximum limit unnecessarily
# params={"page": 1, "limit": 200}
```

## Error Handling

Always handle potential errors in your applications:

```typescript
try {
  const response = await fetch(
    "https://prod.api.sauron.outlight.fun/api/channels/search?q=crypto&limit=10"
  );
  
  if (!response.ok) {
    const error = await response.json();
    console.error('API Error:', error);
    // Handle error appropriately
  }
  
  const data = await response.json();
  // Process data
} catch (error) {
  console.error('Network Error:', error);
  // Handle network errors
}
```
