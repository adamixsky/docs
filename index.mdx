## Popular Endpoints

### Channels API
- [Search Channels](/api-reference/channels/search-channels) - Find channels by keywords
- [List Channels](/api-reference/channels/list-channels) - Get paginated channel lists
- [Channel Details](/api-reference/channels/channel-details) - Comprehensive channel stats
- [Channel Calls](/api-reference/channels/channel-calls) - View tokens called by channels

### Tokens API  
- [Search Tokens](/api-reference/tokens/search-tokens) - Find tokens by address or symbol
- [Recent Tokens](/api-reference/tokens/recent-tokens) - Get recently called tokens
- [Most Called Tokens](/api-reference/tokens/most-called-tokens) - Discover trending tokens
- [Token Details](/api-reference/tokens/token-details) - Complete token information

## Quick Example

```bash
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels/search?q=crypto&limit=10"
```
