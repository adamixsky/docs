# Outlight API Documentation

Welcome to the **Outlight API** – a REST API providing analytics and data for Telegram and Twitter channels, as well as tokens they promote.

**Base URL:** `https://prod.api.sauron.outlight.fun`  
**Version:** `1.0.0`

## Features
- Search and analyze social media channels (Telegram, Twitter/X)
- Track token mentions and performance
- Access historical and statistical data

### Platforms
Supported platforms:
- `telegram`
- `twitter`

### Timeframes
Supported values:
`1h`, `24h`, `7d`, `30d`, `all`

### Data formats
- **Dates:** ISO 8601 (`2025-10-08T12:00:00Z`)
- **Numbers:** returned as strings (for precision)
- **Pagination:** standard `page` + `limit`
