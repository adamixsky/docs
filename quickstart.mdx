This guide helps you make your first API call to Outlight.

https://prod.api.sauron.outlight.fun

# Channels API

## 🔍 Search Channels
Search for channels based on a text query.

<APIPlayground
  method="GET"
  url="https://prod.api.sauron.outlight.fun/api/channels/search"
  queryParameters={{
    "q": "string (optional) - search term",
    "limit": "number (required) - results limit"
  }}
  responseExample={{
    "channels": ["Channel"],
    "count": 0
  }}
/>

---

## 📄 List Channels (with pagination)
Retrieves a paginated list of channels with sorting options.

<APIPlayground
  method="GET"
  url="https://prod.api.sauron.outlight.fun/api/channels"
  queryParameters={{
    "page": "number (optional, starting from 1)",
    "limit": "number (optional, 1–200)",
    "timeframe": "string (optional)",
    "sort": "string (optional)",
    "order": "asc|desc (optional)"
  }}
  responseExample={{
    "channels": ["Channel"],
    "totalChannels": 0,
    "totalPages": 0,
    "currentPage": 1
  }}
/>

---

## 📊 Channel Details
Retrieves detailed information about a specific channel.

<APIPlayground
  method="GET"
  url="https://prod.api.sauron.outlight.fun/api/channels/{channelId}/info"
  pathParameters={{
    "channelId": "string (required) - Channel ID"
  }}
  responseExample={{
    "username": "@example",
    "win_rate": "0.54",
    "avg_gain": "12.5"
  }}
/>

---

## 💬 List Channel Calls
Retrieves a list of tokens called by a given channel.

<APIPlayground
  method="GET"
  url="https://prod.api.sauron.outlight.fun/api/channels/{channelId}/calls"
  pathParameters={{
    "channelId": "string (required) - Channel ID"
  }}
  queryParameters={{
    "page": "number (optional)",
    "limit": "number (optional, max 500)",
    "sort": "string (optional)",
    "order": "asc|desc (optional)"
  }}
  responseExample={{
    "calls": ["ChannelCall"],
    "totalCalls": 0
  }}
/>
