Get started with the Outlight API by making your first request. This guide will walk you through searching for channels that make token calls.

## 1. Authentication

The Outlight API is currently public. **No API key is required.**

All endpoints are, however, subject to rate limiting. For more details, see the [Authentication & Rate Limiting](/api-reference/authentication) guide.

## 2. Your First API Call

Let's find all channels related to "crypto". The `q` parameter is used for the search query, and `limit` controls the number of results.

Simply copy and paste one of the examples below into your terminal or code editor.

<CodeGroup>
```bash cURL
# Use curl to make a GET request from your terminal
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels/search?q=crypto&limit=5"
``````python Python
import requests

# Use the requests library in Python
params = {
    "q": "crypto",
    "limit": 5
}
response = requests.get(
    "https://prod.api.sauron.outlight.fun/api/channels/search",
    params=params
)

if response.status_code == 200:
    data = response.json()
    print(data)
else:
    print(f"Error: {response.status_code}")
``````javascript Node.js
// Use fetch in a Node.js environment
async function searchChannels() {
  const response = await fetch(
    "https://prod.api.sauron.outlight.fun/api/channels/search?q=crypto&limit=5"
  );
  
  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }

  const data = await response.json();
  console.log(data);
}

searchChannels();
```
</CodeGroup>

### Understanding the Response

You will receive a JSON response containing a `channels` array and a `count` of the results. Each object in the array is a **Channel** object.

```json
{
  "channels": [
    {
      "channel_id": "@CryptoGems",
      "username": "CryptoGems",
      "name": "Crypto Gems Official",
      "subscriber_count": 125000,
      "platform": "telegram",
      "win_rate": "72.5"
    }
  ],
  "count": 1
}
```
To understand the full structure of this object, see the [Channel Model](/api-reference/models/channel-models#channel).
