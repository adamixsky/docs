## Setup your first API call

Get started with the Outlight API by making your first request to search for channels or tokens.

### Base URL

All API requests should be made to:

```
https://prod.api.sauron.outlight.fun
```

## Example Requests

### Search for Channels

<CodeGroup>

```bash cURL
curl -X GET "https://prod.api.sauron.outlight.fun/api/channels/search?q=crypto&limit=10"
```

```python Python
import requests

response = requests.get(
    "https://prod.api.sauron.outlight.fun/api/channels/search",
    params={
        "q": "crypto",
        "limit": 10
    }
)

data = response.json()
print(data)
```

```javascript JavaScript
const response = await fetch(
  "https://prod.api.sauron.outlight.fun/api/channels/search?q=crypto&limit=10"
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

</CodeGroup>

## Response Format

All API responses follow a consistent JSON format:

```json
{
  "channels": [...],  // or "data" for token endpoints
  "count": 100,       // or pagination info
  "totalPages": 10,
  "currentPage": 1
}
```

## Common Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | integer | Page number for pagination (starts at 1) |
| `limit` | integer | Number of results per page |
| `timeframe` | string | Time window (e.g., "1h", "24h", "7d", "30d") |
| `sort` | string | Sort field |
| `order` | string | Sort direction ("asc" or "desc") |
